# SAT Holdings

Corporate website for SAT Holdings. Built as a client project. Live at [satholdings.lk](https://satholdings.lk).

## Tech Stack

- **Framework**: Next.js 14 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Animation**: Framer Motion
- **Deployment**: Cloudflare Pages

## Pages

- Home
- Engineering
- Manufacturing
- Products
- Projects
- Contact
- FAQ

## Development

```bash
npm install
npm run dev
```
